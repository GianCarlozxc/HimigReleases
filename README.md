# Himig for Windows

A minimalist music player with dark and light themes, playlists, music discovery, lyrics, and fullscreen playback.

## Download

[Download the latest release](https://github.com/GianCarlozxc/HimigReleases/releases/latest).

- **Portable.exe** runs without installation.
- **Setup.exe** installs Himig and creates shortcuts.
- **SHA256SUMS.txt** contains checksums for verifying the downloaded files.

Windows 64-bit is supported. Music search and streaming require an internet connection. These builds are unsigned. Himig checks this repository at startup and every six hours. Settings includes a manual update check and an automatic-check preference. Updates download inside Himig with progress, cancellation, retry and checksum verification. After downloading, Himig shows "Update completed. Restart required." Choose Restart now to apply the update and reopen Himig automatically. This works for installed and portable copies, and preserves your library and settings.

Your library and settings are stored locally under `%APPDATA%/Himig`. Use Settings to export a backup before moving to another computer.

This repository distributes Windows releases. Application source is maintained separately in a private repository.
